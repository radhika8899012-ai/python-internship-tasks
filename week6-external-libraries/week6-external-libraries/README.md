# Week 6 - Working with External Libraries

## Projects

1. date_time.py - Displays current date and time.
2. weather_app.py - Gets weather details using OpenWeatherMap API.
3. currency_converter.py - Converts currencies.
4. random_user.py - Generates random user details using Faker.

## Libraries
- requests
- Faker
- datetime

## Installation
pip install -r requirements.txt

## Run Programs
python date_time.py
python weather_app.py
python currency_converter.py
python random_user.py
