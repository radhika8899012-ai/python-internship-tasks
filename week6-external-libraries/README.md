# Week 6 - Working with External Libraries

## Projects

1. date_time.py - Displays current date and time.
2. weather_app.py - Shows weather information using API.
3. currency_converter.py - Converts one currency into another.
4. random_user.py - Generates random user details using Faker.

## Libraries Used

- requests
- Faker
- datetime

## Installation

pip install -r requirements.txt

## How to Run

python date_time.py
python weather_app.py
python currency_converter.py
python random_user.py
