# Personal Finance Tracker

## Project Description
This Python project helps users manage daily expenses and monthly budgets.

## Features
- Add expenses
- View expenses
- Edit expenses
- Delete expenses
- Monthly expense report
- Category-wise report
- Set monthly budget
- Export expenses to CSV
- Save data in JSON format

## Technologies Used
- Python
- JSON
- CSV
- DateTime

## How to Run
Run this command:

python run.py

## Files
- run.py: Main Python program
- expenses.json: Stores expense data
- requirements.txt: Project dependencies
- .gitignore: Ignores unnecessary files

## Conclusion
This project helps users track expenses and manage their budget.
