# Personal Information Manager

## Project Overview
This is a simple Python project that collects and displays personal information.

## Features
- Takes the user's name, age, city, and course.
- Calculates age in months.
- Validates age input.
- Displays personal information using f-strings.

## Requirements
Python 3

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the following command:

python personal_info.py

## Testing
Test the program with a valid age and an invalid age.
