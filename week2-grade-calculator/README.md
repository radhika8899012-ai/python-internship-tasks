# Student Grade Calculator

## Project Overview
This project is a Python program that calculates student marks and grades for three subjects.

## Objectives
- Calculate total marks.
- Calculate average marks.
- Find highest and lowest marks.
- Assign a grade based on average marks.
- Validate marks entered by the user.

## Subjects
1. Mathematics
2. Science
3. English

## Grading System
- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: Below 60

## Requirements
- Python 3
- Pydroid 3 or another Python interpreter

## How to Run
1. Open grade_calculator.py in Python.
2. Run the program.
3. Enter the student name.
4. Enter marks for all three subjects.
5. View the result.

## Error Handling
The program checks for invalid numbers and marks outside the range of 0 to 100.
